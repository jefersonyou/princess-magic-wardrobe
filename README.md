# princess-magic-wardrobe
## 공주의 마법 옷장 v0.2.0
승인된 생성 캐릭터와 드레스·신발·왕관을 사용하는 iPad 드레스업 PWA입니다.

개발: `npm ci` → `npm run dev`
빌드: `npm run build`
설치: 배포 주소를 iPad Safari에서 열고 ‘오프라인 준비 완료’ 확인 → 공유 → 홈 화면에 추가.

GitHub Pages: Settings → Pages → Source: **GitHub Actions**로 설정하세요.
main에 push하면 자동 빌드/배포합니다. 상세 안내: [INSTALL.md](INSTALL.md).

현재는 의상 착용 버전이며 스토리 및 음성은 후속 개발 범위입니다.

# 조이의 마법 옷장
조이와 친구들, 요정 루미가 함께하는 6장·18개 이야기의 영어 드레스업 여행.

[게임 열기](https://jefersonyou.github.io/princess-magic-wardrobe/)

- **왕국 여행 → 이야기 시작**: 옷을 끌어다 입히며 친구를 돕고 다음 장소로 이동
- 왕궁·정원·눈의 성·숲·바닷가·무도회와 엔딩
- 영어 음성 174개, 반복 듣기/힌트/자막/개별 볼륨, 무벌점·시간 제한 없음
- 옷장 118종과 캐릭터 4명, 여행 보상과 배경 해금
- 현재 코디·진행 자동 저장, 기존 Stage 1 저장 이어받기
- 런웨이/별빛 무대, 포토타임 PNG 저장·공유, 홈 화면 설치와 오프라인 음성

실행: `npm ci` → `npm run dev`. 빌드: `npm run build`.
검사: `npm test`, `npx playwright test --config playwright.pwa.config.ts` (Chromium 경로 조정 필요).
MP3 파일이 포함되어 플레이에 TTS API가 필요하지 않습니다.

착용 렌더링: 의상25종 팔/손 포함 착용 이미지, 신발13종 발 포함 이미지, 목걸이/팔찌 착용 곡선, 우산 쥔 손/접힌 소매. 조이 얼굴 원본 유지.

이야기에서는 안내된 옷만 착용할 수 있고, 성공하면 다음 안내가 자동으로 나옵니다. iPad 가로/회전 시 화면 안에 전신을 맞춥니다.

가로·세로 화면 모두 아이템 그림을 캐릭터의 안내 원으로 끌어다 놓아 입힙니다. 단순 탭으로는 착용되지 않습니다. 목록은 아이템 이름 부분을 한 손가락으로 위아래로 쓸어 넘기거나 두 손가락으로 넘길 수 있습니다.


## 옷장과 친구
- 조이를 유지하고 루나(보라 땋은 머리), 루비(분홍 머리), 아리아(남색 포니테일)를 추가했습니다. 상단 ‘친구 선택’에서 바꾸며 착장·진행은 유지됩니다.
- 장갑 11종과 팔찌 8종은 의상별 실제 손목을 기준으로 착용하며, 우산 포즈에도 대응합니다. 귀걸이 20쌍 추출 경계와 신발 발목 경계를 정리했습니다.
- 여행의 현재 지시를 수행하면 자동 진행합니다. 다른 아이템은 착용하지 않고 요정 알림으로 현재 목표를 안내합니다. 장소 이동 버튼을 안내 영역 밖에 크게 분리했습니다.
- [확장 이야기 안내](https://jefersonyou.github.io/princess-magic-wardrobe/review/story/index.html): 6장·18케이스·142개 영어 대사. 18개 이야기를 장소별로 선택해 플레이하고, 새 영어 안내와 이유 설명을 들을 수 있습니다.


## v0.11.0 왕국 여행 확장
- 6개 장소 × 3개 상황, 총 18개 이야기를 게임에 연결했습니다. 왕국 여행의 ‘📚 이야기 3개’에서 선택합니다.
- 상황·지시·이유·결과를 담은 새 영어 음성 142개와 한국어 설명. 소리 설정에서 ‘영어 이유 설명도 듣기’를 끌 수 있습니다.
- 지시 이행은 자동 진행하며, 다른 아이템은 알림과 함께 미착용 처리합니다. 복합 지시·클리어/보상·기존 미완료 진행을 보존합니다.
- 기존 진행 중인 에피소드는 원래 목표로 마칠 수 있고, 새 이야기는 언제든 선택할 수 있습니다.

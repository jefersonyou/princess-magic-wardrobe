# v0.11.1 착용 및 드래그 재점검

- 118개 아이템을 독립적으로 착용한 화면, 25개 의상의 우산 자세를 캡처하여 확인합니다.
- 전신에 하나의 연속 좌표 변환을 적용합니다. 머리/목/몸통/다리 변환과 드롭 판정, 포토타임의 역변환이 같은 기준을 사용합니다.
- 일반 의상과 우산용 외투의 목 피부를 원래 캐릭터에서 연결합니다. 옷깃은 그대로 보존합니다.
- 외투 우산 원화의 인접 칸 혼입을 제외하고 겨울 외투 중심을 맞춥니다. 우산 돔, 봉, 손의 위치를 연결합니다.
- 귀걸이는 크기를 줄이고 귓불에 고정합니다. 조이와 세 친구의 서로 다른 귓불 좌표를 사용합니다.
- 나비/초승달 핀의 노출 고리, 장미 빗핀의 빗살은 착용 레이어에서 가립니다. 상품 썸네일은 원래 모양을 유지합니다.
- 모자는 머리 윗면에 맞추고, 지안 꽃 리본과 귀걸이도 같은 착용 크기 기준을 적용합니다.
- 장갑 길이를 손목에서 손끝까지 맞추고, 팔찌/장갑의 드롭 원은 실제 자세의 손목을 따릅니다.
- 목걸이/목도리와 우산, 우산 자세 의상의 드래그 미리보기에 최종 착용용 텍스처를 사용합니다.
- 화면 크기와 무관하게 그림은 드래그 착용, 이름 영역은 한 손가락 목록 스크롤을 지원합니다. 두 손가락 스크롤도 유지합니다.
- 드롭 원은 기존 반경의 1.35배, 최소 42 논리 픽셀이며 흰색 보조 테두리와 반투명 배경을 표시합니다. 표시된 원과 실제 드롭 판정 범위가 같습니다.

모든 단일 아이템과 위 조합을 검사하며, 118종의 모든 가능한 조합을 전수 열거한 것은 아닙니다. 브라우저 검증은 Chromium 터치 에뮬레이션을 사용합니다.
